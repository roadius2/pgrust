## Appendix: 016 repro and page-chain parser
**Repro.** On a fresh pgrust server:
1. Run `CREATE EXTENSION vector; CREATE TABLE tst (v vector(1900)); CREATE INDEX ON tst USING hnsw (v vector_l2_ops);`.
2. Repeat: `TRUNCATE tst`, then `pgbench -n -c 10 -t 1 -f insert.sql`, where `insert.sql` inserts one `ARRAY[random() x1900]` row. Stop at the first round whose output contains "cycle detected". It usually fails in round 1.
3. Stop the server cleanly so pages are flushed, then run the parser below on the file at `pg_relation_filepath('tst_v_idx')`.

On 2026-10-04 the chain was sound when the error fired: 10 blocks, a 9-page chain that terminates, no page with two predecessors.

```python
# hnsw_chain.py <index relation file>: walk an HNSW index's page chain.
# Special space = last 8 bytes of each 8 KB page: uint32 nextblkno, uint16 unused, uint16 page_id (0xFF90).
import struct, sys
data = open(sys.argv[1], "rb").read(); BLCKSZ = 8192; n = len(data) // BLCKSZ
def opaque(b):
    nxt, _, pid = struct.unpack_from("<IHH", data, b * BLCKSZ + BLCKSZ - 8); return nxt, pid
magic, version, dims, m, efc, eblk, eoff, elvl, insert_page = struct.unpack_from("<IIIHHIHhI", data, 24)
print(f"blocks={n} magic={magic:#x} dims={dims} m={m} insertPage={insert_page}")
print("pages with wrong page_id:", [b for b in range(n) if opaque(b)[1] != 0xFF90][:10])
seen, order, b = {}, [], 1
while b != 0xFFFFFFFF:
    if b >= n: print(f"CHAIN POINTS PAST EOF: -> {b}"); break
    if b in seen: print(f"CYCLE: block {order[-1]} -> {b}"); break
    seen[b] = len(order); order.append(b); b = opaque(b)[0]
else:
    print(f"chain from head terminates after {len(order)} pages")
print("blocks not reachable from head:", len(set(range(1, n)) - set(order)))
pred = {}
for x in range(n):
    nx = opaque(x)[0]
    if nx != 0xFFFFFFFF: pred.setdefault(nx, []).append(x)
print("blocks with >1 predecessor:", {k: v for k, v in pred.items() if len(v) > 1})
```
